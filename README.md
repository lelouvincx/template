# Personal-project starting point

Generate a repository from this template, clone it, and ask your agent to follow [AGENTS.md](AGENTS.md).

- Bootstrap: `.agents/setup`.
- Project commands and customizations: `.agents/project`.
- Optional Amp configuration: `.agents/configure-amp`.

Shared infrastructure comes from `lelouvincx/agent-skills`. Choose your application stack separately and replace this README with the project's purpose.
